常见问题

研途适合哪些团队？

研途面向成人学术服务团队：论文与升学顾问、留学申请顾问、科研与算法辅导、数据分析人员，以及负责内容宣发和项目统筹的同事。无论是独立顾问还是团队里的某个岗位，都可以用它管住手上的咨询和交付。

需要自己准备 AI 模型吗？

需要。首次打开后进入「设置 → 模型」，点击「添加模型」，默认选中 OpenRouter，填入你的 API Key 即可开始使用。也可以接入其他兼容的模型服务。

支持哪些消息渠道？

微信、企业微信和飞书，Windows 和 Mac 都支持。研途按这台电脑上已登录的微信、企业微信客户端同步消息，飞书通过授权接入，在「扩展 → 渠道 → 消息采集接入」里开启；首次开启时按提示完成系统授权。

消息同步会用到电脑上的 Python 3（Windows 需要 64 位 Python 3.10 或更新版本）。也可以把本地文件夹设为监听目录，放进去的新文件会自动变成任务。

回复会自动发给客户吗？

不会。研途为你起草回复草稿，你可以修改、复制后在原渠道发出；所有需要发送的环节都由你确认。

数据保存在哪里？

保存在你自己的电脑上。任务、会话、交付文件和运行记录都在本机；只有在调用模型时，相关内容才会发送给你配置的模型服务。

支持哪些系统？

Windows 10 与 Windows 11（64 位），以及搭载 Apple 芯片（M1 及更新）的 Mac，需 macOS 11 或更高版本。详见下载页。

怎么更新到新版本？

在应用里打开「设置 → 关于」，点击「检查更新」，有新版本时可以直接下载。也可以随时回到下载页获取最新安装包。
