安装说明

三步装好，
首次打开照着做

Windows 与 macOS 都会在第一次打开新下载的应用时请你确认一次，确认之后就和普通应用一样直接打开。

Windows

  1. 双击运行 Yantu-2.1.21-win-x64.exe。如果出现「Windows 已保护你的电脑」，点击「更多信息」，再点「仍要运行」。
  2. 选择安装方式（仅为我安装或为所有用户安装）和安装位置，点击「安装」。
  3. 安装完成后，从桌面或开始菜单打开研途。

macOS

  1. 双击打开 Yantu-2.1.21-mac-arm64.dmg，把 研途（Yantu）拖进「应用程序」文件夹。
  2. 第一次打开时如果提示无法验证开发者，先点「完成」，再打开「系统设置 → 隐私与安全性」，在页面底部点击「仍要打开」，输入开机密码确认。
  3. 如果提示「已损坏，无法打开」，打开「终端」运行下面这行命令，然后再次打开研途： xattr -dr com.apple.quarantine /Applications/Yantu.app
装好之后

三步开始第一项任务

01

添加模型

打开 设置 → 模型，点击「添加模型」。默认选中 OpenRouter，填入你的 API Key 保存即可；也可以选择其他兼容的模型服务。

02

接入工作来源

在输入框的「＋」菜单点「前往工具设置」，进入 扩展 → 渠道：在「消息采集接入」里打开微信、企业微信、飞书的同步，在「本地文件夹」里添加要监听的目录。消息同步需要电脑上装有 Python 3（Windows 为 64 位 3.10 或更新版本）。

03

交出第一项任务

点 新会话，选一个「一句话开工」的工单，或者直接描述你要交付的东西，研途会接着把它做完。

下载与安装常见问题

我的电脑能装吗？

Windows 需要 Windows 10 或 Windows 11 的 64 位系统。Mac 需要 Apple 芯片（M1 及之后的所有 M 系列芯片）并运行 macOS 11 或更高版本。

在 Mac 上可以点击左上角苹果菜单 →「关于本机」，看到「芯片：Apple M…」即可安装。

Intel 芯片的 Mac 可以用吗？

当前的 macOS 安装包面向 Apple 芯片（M1 及更新）构建，Intel 芯片的 Mac 无法运行。

为什么第一次打开需要额外确认？

Windows 和 macOS 会对刚从网上下载的应用做一次来源确认。按上面的安装说明点击「仍要运行」或「仍要打开」即可，之后打开不再询问。

怎么确认下载的安装包完整？

对照上方卡片里的 SHA-256 校验值：

Windows：在 PowerShell 中运行 Get-FileHash .\Yantu-2.1.21-win-x64.exe

macOS：在终端中运行 shasum -a 256 ~/Downloads/Yantu-2.1.21-mac-arm64.dmg

输出的值与页面上一致，说明文件完整。

装好后需要登录账号吗？

不需要注册研途账号。打开后在「设置 → 模型」添加你的模型服务就能开始使用。

怎么更新和卸载？

更新：在应用里打开「设置 → 关于」，点击「检查更新」；也可以回到本页下载最新安装包覆盖安装。

卸载：Windows 在「设置 → 应用」里找到研途卸载；macOS 把「应用程序」里的研途（Yantu）拖到废纸篓。
